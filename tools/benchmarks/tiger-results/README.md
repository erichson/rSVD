# Tiger rank illustration

The figure uses the **`tiger` matrix bundled with rsvd** to show how retained
rank affects image reconstruction. Its three reconstructions are separate
calls to `rsvd(tiger, k, p = 10, q = 2)`, each
preceded by `set.seed(42)`, for `k = 10, 50, 150`. These results illustrate
reconstruction quality and factor size; they provide no timing comparison.

For an `m` by `n` real matrix, the stored factors contain `m*k` entries in `U`,
`k` in `d`, and `n*k` in `V`. Their entry count relative to the dense matrix is

```r
k * (m + n + 1) / (m * n)
```

This ratio counts **numbers stored** under a common numeric representation.
JPEG compression, disk sizes, and R object overhead are outside this count.
It also excludes comparisons between 8-bit image pixels and 64-bit factors,
which use different representations. Materializing the dense reconstruction
requires the full image-sized matrix again.

`summary.csv` records the unrounded relative Frobenius errors and entry counts.
Errors are computed on the floating-point reconstructions before any display
clipping. Every panel uses the same grayscale limits, `[0, 1]`, and orientation,
equivalent to `image(tiger)`. Values outside that interval are clipped for display
only; the CSV records their extent. The images are resized only for the layout,
using the same interpolation for each panel.

## Reproduce

From the repository root, with the candidate package installed:

```sh
Rscript tools/benchmarks/illustrate-tiger.R \
  --results tools/benchmarks/tiger-results --images /tmp/rsvd-tiger
python tools/benchmarks/render-tiger.py \
  --results tools/benchmarks/tiger-results --images /tmp/rsvd-tiger \
  --figures man/figures --pdfs tools/benchmarks/figures
```

Use `--library /path/to/R/library` in the first command when needed. R 4.4 or
later and Matrix 1.7-0 or later are required. The renderer requires NumPy,
Matplotlib, and Pillow. `metadata.csv`, `session-info.txt`, and
`figure-environment.json` record the measured and rendered environments. The
larger binary image intermediates remain outside the repository and are
regenerated by the first command.

The README PNG uses 120 dpi at the figure's layout size; the PDF uses 180 dpi
for its image panels and retains vector text. The smaller PNG keeps installed
documentation compact. Both exports use the same numerical reconstructions,
display limits, and layout. These rendering choices leave the measured errors
unchanged.

The recorded source commit is the checkout HEAD at generation time. Source-file
hashes identify the numerical code independently of version or documentation
edits in the working tree.
